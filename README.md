## 📖 프로젝트 개요
스타벅스 사이렌 및 매장 POS를 클론 코딩해 사용자와 매장을 연결하는 주문·결제 시스템을 구현과
출퇴근/점심 시간대의 대량 주문 처리 능력을 주요 과제로 삼아 부하테스트 경험을 학습

### 📅 진행 기간
- MVP 기획 및 개발 : 2025. 06. 01. ~ 2025. 07. 02
- 부하테스트 진행 & 개선 : 2025. 07. 03. ~ 2025. 07. 12

### 핵심목표
- 협업을 통한 커뮤니케이션 능력 및 팀워크 강화
- Spring Boot와 React 간의 API 통신 구조 이해 및 구현
- 단순한 복제를 넘어서, 서비스 개발의 전반적인 흐름과 구조를 체계적으로 학습
- 부하 테스트를 통한 성능 개선 경험

## 🔧 기술 스택
### Backend
- **Language** : Java 21
- **Framework** : Spring Boot 3.5.0
- **ORM** : Spring Data JPA
- **DB** : Postgres
- **Build Tool** : Gradle

### Infrastructure & DevOps
[![infra,devops](https://skillicons.dev/icons?i=git,github,docker,aws,githubactions)](https://skillicons.dev)
- **Cloud Platform** : AWS (ECS, RDS)
- **Container** : Docker
- **CI/CD** : GitHub Actions
- **VCS** : Git, GitHub
